# Project rules

At this time, I want to use you to discuss code, rather than have you commit code directly. I'll ask you to show code on this screen and then, if necessary, I'll ask you to either create a new branch, or zip files.

You must NEVER commit code to a main / master branch. If I mistakenly ask you to do so, stop and ask me whether I want a new branch instead.

You don't need my permission to render diffs or build and present zip files.
